Import classement final (CSV)

Importe le classement complet d'une course terminée. Met à jour les coureurs et les arrivées en une seule opération. La course est automatiquement marquée Terminée.

🏆

Glissez le fichier CSV du classement ou cliquez pour parcourir

Format : position,dossard,nom,prenom,sexe,categorie,club,temps

Format du fichier CSV
position,dossard,nom,prenom,sexe,categorie,club,temps
1,42,DUPONT,Jean,M,SE,Trail Club 34,01:23:45
2,17,MARTIN,Sophie,F,V1,Les Gazelles,01:25:30
3,88,BERNARD,Pierre,M,V2,,01:26:10
  • position : optionnel (recalculé automatiquement)
  • dossard : requis
  • nom, prenom, sexe, categorie, club : optionnels si les coureurs sont déjà importés
  • temps : requis — format HH:MM:SS
